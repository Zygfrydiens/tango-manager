# Knowledge

Reference material the collaborator reads as **background knowledge** — richer prose than the structured
databases in `data/`. The structured graph (figures, qualities, musicality ideas, concepts) is the
working memory; this folder is the library behind it.

- **`musicality.md`** — the full **CPE-8 + ROLA** anti-monotony framework (Patryk's own system). The
  source of truth for musicality; `data/musicality_ideas.json` and `data/concepts.json` index into it.
- **`playlist_tango_technique_at_home.md`** — technique reference (figure mechanics, drill index) behind
  the seeded figure entries. Background only — not a training program.
- **`ideas.md`** — Patryk's **idea inbox / lab notebook**: half-formed ideas and personal discoveries
  before they become structured entries. The collaborator checks this when he's brainstorming and logs
  new hunches here. Newest at the top, dated.
- Drop more here as it comes up: class/teacher notes, figure breakdowns, festival notes, video
  observations. Anything dated and personal that's too rich for a structured entry but worth keeping.

> Exercises/drills in these files are **reference for understanding a figure or idea**, not a practice
> plan. Tango Manager is a knowledge collaborator, not a coach — see `CLAUDE.md`.
