Drop a sound file here named checkin.wav / checkin.mp3 / checkin.m4a / checkin.wma
and the scheduled check-in will play it to grab your attention when a Tango Coach
session opens.

A tango track works nicely here.

If no file is present, checkin.ps1 falls back to C:\Windows\Media\Alarm01.wav,
and then to the system Exclamation beep.
