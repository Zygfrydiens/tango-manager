# Archive

These files belong to the **old Tango Manager** — a weekly coaching / practice-planning /
scheduling system. That purpose was retired on 2026-06-26 when the project became a
**knowledge-system collaborator** (see the new `CLAUDE.md`). Nothing here is loaded by the
skills anymore; it's kept only so the change is reversible and the old reasoning isn't lost.

| File | What it was | Why retired |
|------|-------------|-------------|
| `skills/tango-coach.SKILL.md` | Relationship/coaching voice: weekly review, milonga strategy, motivation/burnout watch | Coaching + accountability framing removed |
| `skills/practice-planner.SKILL.md` | Drill prescription, session/dose design, "active topics" | Planning/training cadence removed |
| `data/state.json` | Phase, active topics, week counter, adjustments log | "Active topics" + week counters removed |
| `data/weekly_plan.json` | The week's class/practica/milonga/solo slots | Weekly scheduling removed |
| `data/template.json` | Daily session-log template (pre/post-dance) | Check-in / session-log framing removed |
| `data/observations.jsonl` | Append-only mood/joy/progress signal log | Progress accountability removed |
| `data/topic_library.json` | Training catalogue (active/parked/solid + drills) | **Mechanical notes mined into `data/figures.json`**, then archived |
| `scripts/schedule.ps1`, `scripts/checkin.ps1` | Windows Task Scheduler check-ins | Scheduled check-ins removed |
| `knowledge/solo_routine_45min.md` | A fixed 45-min solo practice routine | Training-cadence artifact |

**Kept in the live project** (still useful as background knowledge): `knowledge/musicality.md`
(the CPE-8 + ROLA framework — now integrated into the knowledge databases),
`knowledge/playlist_tango_technique_at_home.md` (technique reference), `data/transcripts/`,
and `scripts/clean_vtt.py`.
